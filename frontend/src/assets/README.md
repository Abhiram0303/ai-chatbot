# NOVA Logo Assets
 
The official canonical logo image is located at:
- `frontend/src/assets/nova-logo.png`
- `frontend/public/assets/nova-logo.png`
- `frontend/public/favicon.png`
- `frontend/public/favicon.ico`

The `NovaLogo.jsx` component automatically renders this canonical artwork across:
1. Sidebar navigation header
2. Hero Welcome empty-state section
3. NOVA Assistant message avatar & typing indicator
4. Login and Signup authentication headers
5. Browser tab favicon
